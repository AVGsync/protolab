# Дизайн ProtoLab: «Стенд»

ProtoLab выглядит как прибор на лабораторном столе, а не как веб-панель: логический анализатор для TCP. Данные
главные, оформление молчит. Пользователь здесь реверс-инженер: ему нужны байты, происхождение каждого вывода и
спокойный экран, на котором ничто не кричит без причины. Значения токенов живут в
`frontend/src/app/styles/index.css`, правила использования в `frontend/README.md`.

## Принципы

1. **Один главный предмет на экране.** Рабочая область сессии: байты. Проверка: итог одной полосой, дальше детали.
   Второстепенное (хеши, условия воспроизведения, формат импорта, кодировки поиска) свёрнуто в `Disclosure`.
2. **Нормальное состояние молчит.** Метка появляется только при отклонении: нарушение, пропуск, устаревание.
   Завершённая проверка и неизменённая запись ничего не показывают, пустой список задач скрыт.
3. **Цвет значит, а не украшает.** Каждый цвет отвечает за одну роль (таблица ниже). Один акцент на всё приложение.
4. **Линии вместо коробок.** Панели отделяет линия в 1px. Нет карточек в карточках, теней и больших радиусов.
5. **Моноширинный для данных, гротеск для слов.** Числа в таблицах табличные и выровнены по разряду.
6. **Происхождение всегда рядом.** Любое число ведёт к байтам; неизвестное рисуется штриховкой и `??`, не нулём.
7. **Один ритм.** Одинаковые поля страниц (16px), одна шкала кеглей, одна высота строки таблицы (28px).

## Токены (используются в коде)

| Роль | Тёмная | Светлая | Где |
|---|---|---|---|
| `bg` / `surface` / `surface-2` | `#101112` / `#161718` / `#1d1f20` | `#eceae5` / `#f8f7f3` / `#f0eee9` | фон «колодца» данных / панели / наведение |
| `line` / `line-strong` | `#2b2e30` / `#5e6469` | `#d6d3cc` / `#8a867e` | разделитель / граница контрола |
| `fg` / `muted` | `#e6e7e4` / `#8e9296` | `#1a1a18` / `#5c5a55` | текст; `muted` не меньше 5.7:1 к фону |
| `selection` | `#243b42` | `#d4e6e8` | фон выделенных байтов и строк (подложка, не акцент) |
| `accent` (единственный) | `#ff6a2b` | `#b83a08` | маркер раздела, фокус, курсор, живой прогресс, штриховка в логотипе |
| `ok` `warn` `danger` | `#76c893` `#e5a93b` `#ff5c6a` | `#266b43` `#8f5b00` `#c21f36` | разобрано / неполное / нарушение |
| `unknown`, `info` | `#868a8e`, `#94a9c2` | `#5c5a55`, `#3f5f82` | неизвестные байты и тип; нейтральная заметка |
| `ch-c2s` / `ch-s2c` | `#e8c450` / `#4cc7d6` | `#86600a` / `#007380` | направление потока: янтарь и циан |
| `field-1..4`, `field-lane-1..4` | пастельные тона | насыщенные тона | подчёркивание байтов поля и подложка в дорожке |
| `heat-0..5` | от `#2e3032` до `#f8c885` | от `#e4e1db` до `#5c101f` | изменчивость столбца при сравнении |

Палитра светлой темы тёплая («бумага»), тёмной нейтральная графитовая; зелёного оттенка в нейтралях нет, чтобы он не
путался с `ok`. Все цвета текста проходят 4.5:1 в обеих темах (проверено расчётом WCAG, см. раздел «Проверка»).

**Типографика.** IBM Plex Sans (интерфейс) и IBM Plex Mono (байты, смещения, значения), оба OFL, кириллица, поставляются
из npm (офлайн). Шкала из пяти кеглей: `2xs` 11 (теги, счётчики), `xs` 12 (вторичный текст, данные таблиц), `sm` 13
(основной), `lg` 16 (заголовок страницы), `xl` 20 (одна ключевая цифра). Hex-сетка 13px, ячейка 26px. Утилита
`legend`: тот же Plex Sans с осью ширины 85% (в переменном файле `wdth` 75 до 100): подписи столбцов и полей уже
текста, русские заголовки не переносятся. Заглавные буквы для подписей не используются.

**Сетка.** Шаг 4px (`1`, `2`, `3`, `4`, `6` по Tailwind: 4, 8, 12, 16, 24). Поля страницы 16px, как в шапке. Строка
таблицы 28px, панель 32px, контрол 28px. Радиус 3px только у контролов. Тень только у всплывающих окон.

Страницы Linear и Vercel не открылись напрямую из песочницы, поэтому их положения взяты из описаний в поиске; остальные
ссылки проверялись по содержимому. JetBrains Mono (OFL) рассмотрен для hex и отвергнут: Plex Mono рисует цифры и
буквы A-F так же в одной семье с гротеском и даёт точку в нуле, смешение семейств не нужно.

## Чего избегаем

Градиентов (был в логотипе, убран), свечения и стекла, пленочного шума и миллиметровки (были, убраны), эмодзи,
разноцветных плашек-бейджей (вместо них квадрат 7px и текст), карточек внутри панелей, больших скруглений, теней у
панелей, иллюстраций в пустых состояниях, заглавных меток и разрядки, второго акцентного цвета, постоянных
пояснений на экране (пояснение живёт в `title`, во `?` или за `Disclosure`).

## Проверка

`npm run typecheck`, `npm run lint -- --max-warnings=0`, `npm test`, `npm run build`. Визуально: оба режима темы при
1440x900 и 1280x800 на каждом маршруте mock-режима (`npm run dev:mock`). Контраст: текст не ниже 4.5:1 (формула WCAG
для пар «токен на фоне» в обоих темах).
